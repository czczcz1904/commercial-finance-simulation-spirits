# Commercial Performance & Trade Investment Analysis — Vietnam Spirits Market

**Independent learning project | Synthetic data | Excel / Power Query / Power BI**

This project demonstrates a practical commercial-finance workflow: generating and validating structured sales, depletion, inventory, budget, trade-investment and retail-price data; preparing the data for analysis; and building a management dashboard with actionable commentary.

> **Important disclaimer:** This is an independent educational simulation. It is not created, sponsored, endorsed or supplied by Pernod Ricard. All transaction records, prices, costs, budgets, distributors, retailers, volumes and business scenarios are fictional and generated by code. Public brand names are used only to create a realistic learning context. No internal company information is represented.

## Business questions

1. Are sales and volume tracking against budget?
2. Is Sell-in aligned with Depletion, or is distributor inventory building up?
3. How do discounts and allowances affect Gross-to-Net Sales?
4. Are A&P actual expenses within budget?
5. How do observed retail prices vary by SKU, channel and region?

## Dataset scope

- Period: January–December 2025 (synthetic monthly facts; daily date dimension)
- Brands: Chivas Regal, Ballantine's, Jameson and Absolut
- SKUs: 8 illustrative pack-size combinations
- Regions: North, Central and South
- Channels: On-trade and Off-trade
- Distributors: 12 fictional distributors
- Retailers: 24 fictional outlets
- Currency: VND; case volumes are in cases

## Re-create the synthetic dataset

Requirements: Python 3.10+; the generator uses only the Python standard library.

From the repository root:

```bash
python scripts/generate_data.py
```

The script overwrites the CSVs in `data/raw/` with the same dataset each time because the random seed is fixed. Change `SEED` in the script only when you intentionally want a different scenario.

## Embedded scenarios for analysis

The dataset intentionally includes several fictional patterns so that the analyst can practice asking "what happened, why, and what should the business do next?":

- Distributor `DST-S-01` receives unusually high Sell-in during January–April while its Depletion rate is weaker, creating a stock build-up pattern.
- Absolut Off-trade has higher modeled A&D rates in June–August.
- Selected Chivas Regal South On-trade and Absolut North Off-trade A&P periods exceed the modeled budget.
- Absolut retail prices in North have wider variation during June–August.

These are **designed scenarios**, not findings about actual brands, distributors, channels or markets.

## Validation

Run the generator and inspect `docs/validation_report.txt`. The script checks:

- Unique fact-table grains.
- Gross Sales less A&D equals Net Sales.
- A&D components add to Total A&D.
- COGS reconciles to physical cases shipped times standard cost.
- Inventory roll-forward reconciles and closing stock is non-negative.
- Fact foreign keys map to dimension tables.
- Sell-in and Depletion detail reconcile to the inventory movement table.
